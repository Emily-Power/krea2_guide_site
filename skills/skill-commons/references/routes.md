# 三线路由

> 项目内单源：9 个领域 skill 共用。各 SKILL.md 的路由块引用本文件，只保留本线判别句。

## 1. 九宫格

三线 × 三环节，一次定线定环节：

| 环节 \ 线 | 露骨（explicit） | 纯欲（暗示不露骨） | SFW（无暧昧写真） |
|-----------|-----------------|--------------------|--------------------|
| 剧本 / 导演 / 故事集（先人话） | `erotic-director` | `youth-seduction-director` | `figure-photo-director` |
| 静帧提示词 / 出图 | `erotic-prompt` | `youth-seduction-prompt` | `figure-photo-prompt` |
| 视频提示词 / MiniMax H3 | `erotic-prompt-minimax` | `youth-seduction-minimax` | `figure-photo-minimax` |

一次对话只做一个环节。用户要剧本 → 只出剧本与交接条；要出图 → 静帧 skill 新开对话；要出视频 → MiniMax skill 新开对话。

## 2. 环节判断

先看用户要的是哪个环节，再看线：

| 用户说法 | 环节 |
|----------|------|
| 扩充想法 / 想个创意 / 先定风格再写 / 只有一句想拍成片 / 这套拍什么调性 | 创意（`creative-director`，出简报确认后转导演环节） |
| 写剧本 / 导演 / 故事集 / 分镜故事 / 长镜头 / 先人话再出图 | 导演 |
| 写提示词 / 出图 / 生成图片 / 一套 N 张 / 对照出图 | 静帧 |
| 写视频提示词 / MiniMax / 出视频 / R2VA / T2VA / 一条 N 秒 | 视频 |
| 无人体题材（广告/产品/口播/风物）的 MiniMax 提示词 | `minimax-h3-r2va-enhanced-prompt`（通用父层，不读本层） |
| 教学站导演台点菜 / H3 魔改导演台 JSON | 不是本体系，不接 |

创意环节是导演环节的**上游**：用户想法薄时先出简报再写戏；用户带完整剧本或交接条时跳过创意。

## 3. 线判断（按尺度）

| 用户说法 | 线 |
|----------|-----|
| 露骨 / NSFW / 插入 / 自慰进入 / 性器写清 / 最色 / 大胆 | 露骨线 |
| 纯欲 / 独处诱惑 / 暗示暧昧 / 白月光 / 禁欲 / 不要露骨 | 纯欲线 |
| 街拍 / 旅拍 / 时尚 / 运动 / 职业 / 证件 / 完整着装 / 无暧昧 | SFW 线 |

**边界例句**（跨线判别的常用说法）：

- 「少女私房但不要欲望」→ SFW figure + soft-boudoir；「少女私房要暧昧不要露骨」→ 纯欲线。
- 「别写太色但要有欲望感」→ 纯欲；「最色 / 拉满」→ 露骨；「更清新一点」→ SFW 或降 I。
- 线判断按用户最后表达为准；跨线时路由并停，不要在本线内硬写。

## 4. 视频线决策树

用户要 **视频 / MiniMax** 时，按此顺序走，第一个命中即停：

```
视频 / MiniMax 请求
├─ 露骨（插入/自慰进入/性器写清/最色）          → erotic-prompt-minimax
├─ 纯欲（独处暗示/不要露骨/白月光/禁欲）        → youth-seduction-minimax
├─ SFW 人体（街拍/旅拍/时尚/运动/职业/证件）    → figure-photo-minimax
└─ 无人体题材（广告/产品/口播/风物/非三线人体） → minimax-h3-r2va-enhanced-prompt（通用父层）
```

- `minimax-h3-r2va-enhanced-prompt` 是通用父层 + 兜底：三线视频 skill 不接的题（无人体、跨线混题、非东亚写真体系）都归它，它不读三线 catalog，只读 `../minimax-h3-core/`。
- 三线视频 skill 只接本线题；接不下时**路由 r2va-enhanced，不要在本线内硬写**。
- 静帧环节同理：三线静帧 skill 接不下 → 说明「无对应静帧 skill，请走通用生图流程」；不硬套三线。

## 5. 兜底与互斥

- 未指定人种、只说场景与尺度词 → 仍按线判断，人种/年龄等空位用 `defaults.md`。
- 线内细节（E 级 / I 级 / 连接点 / 组合包）一律去对应**静帧 skill** 查，导演与视频 skill 不另建目录。
- 视频线的 H3 字段与工作流规范在 `../minimax-h3-core/`，不在领域 skill 里另写。
- 导演环节禁止写生产提示词；静帧/视频环节只写词，默认不调用生图生视频工具。

## 6. 新线扩展协议

新增一条线（例如「唯美古风」）必须一次做全，缺一不建：

1. **三件套**：`<线>-director`（剧本）+ `<线>-prompt`（静帧）+ `<线>-minimax`（视频），定位与互斥写进各自 SKILL.md。
2. **九宫格加一行**：本文件 §1 九宫格表补一行三列。
3. **决策树加一行**：§3 线判断表与 §4 视频线决策树各补一条判别。
4. **公共层先继承后覆盖**：`boundaries.md` / `defaults.md` 公共规则默认生效；新线特有禁区与默认写在本线 SKILL.md，公共层**不加**线专属内容。
5. **静帧 catalog 独立**：新线的分支/组合包/深度库放本线 `references/`，不塞进其他线。
