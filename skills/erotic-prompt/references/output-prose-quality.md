# 输出正文质量规范（Output Prose Quality）

本文件约束 **形态 A 英文四段** 与 **形态 B 短密** 的**文字本身**——不是再列 fetish，而是把句子写到「模型能画、人能读、色气落地」。

适用于 **Krea 2** 与 **Seedream** 的形态 A（同一五标准+连接点）。  
**执行：** 七层完整句；连接优先；**高密四段版式（段间空行）**；全文默认 **200–400** 词；Seedream 更精炼并可附 B。  
分层 → [`krea2-qwen-te-layered-prompting.md`](krea2-qwen-te-layered-prompting.md)

> **三 skill 统一版式（erotic / figure / youth）：**  
> `This is a…` 空行 `Main subject:` 空行 `Environmental background:` 空行 `Composition and atmosphere:`  
> 首句 = 角度+景别+画幅 + **with 摄影类型** + **定格瞬间**；Main 以 `An adult…` 多句全链（有行为必含连接点）；禁止短开篇、禁止四段粘连。  
> 窗盒手办/产品静物等题材：**同一四段标签与空行**，仅首句摄影类型改为 `commercial collectible packaging photography` 等。

## 1. 正文质量五标准（强制自检）

| # | 标准 | 合格 | 不合格 |
|---|------|------|--------|
| 1 | **可视** | 每句能对应画面里一块像素 | “very sexy”“erotic atmosphere” 空喊 |
| 2 | **具体** | 有可替换的名词/动词/方位 | “a woman posing” |
| 3 | **单帧** | 一个瞬间，无 then/after/begins to | 时间线剧本 |
| 4 | **连接优先** | 有行为则 1 句写死连接点 | 只写脸美环境大 |
| 5 | **密度** | 信息密、少水词 | 同义反复、标签刷屏 |

**水词黑名单（正文少用或不用）：**  
`sexy, hot, erotic, beautiful, stunning, gorgeous, perfect, amazing, lovely, seductive`（除非紧跟具体动作/材质）  
改写：`seductive` → `half-lidded eyes fixed on the lens, lower lip caught between teeth`

**禁令转正面（用户说 no X / 避免 X → 写正面材质语言，禁止在正文复述禁令）：**

| 用户禁令 | 正面写法 |
|---------|---------|
| no gloss / no bloom / no flare | matte to satin surfaces, controlled highlights without halation |
| NOT photorealistic | stylized illustrated forms with simplified dimensional shading |
| 不要反光/闪 | soft diffuse highlights |
| 不要多余饰品 | clean unadorned surfaces |
| 不要全描线 | lost-and-found edges with selective contour at the focal area |

**名词色安全（防颜色名词生成物体）：**

- 不用 `lemon / salmon / lavender` 等裸名词色 → 写 `bright yellow / soft pink-orange / pale purple`。  
- 花纹写 `striped / spotted / mottled / solid`，不用动物名词色（除非动物本尊在画里）。

只写：**相对位置 + 触碰点 + 权力/助色关系**。


### 2.4 `Environmental background:`（约 **40–80** 词）

**2～5 个锚点**，服务情欲，不装修；可用 em-dash 串特质：

- 床/墙/门/窗/蒸汽/灯 各最多一句特质  
- 时代杂物最多 1 个（房卡、空衣架、雾镜）  
- 超常场景：1 个法阵/凝胶/虚空即可  
- 窗盒题材：box sleeve / PET window / molded tray / back card graphic  

差：逐件描写床头柜品牌、地毯花纹、窗外建筑名。

### 2.5 `Composition and atmosphere:`（约 **40–75** 词）

必须有：

1. **占框**（subject/box fills most of frame + thin margin）  
2. 绝对视觉中心（结合部 / 敞开胸 / 脸）  
3. **主光 + fill/rim**，落在解剖/结合部  
4. 景深与虚化对象  
5. 一句情绪张力 + 色盘  
6. 质量词 + 静帧类型：`masterpiece, best quality, photoreal erotic still`

## 6. 中文释义质量（第二部分）

中文不是英文机翻，而是**用户可读的导演说明**：

| 条 | 要求 |
|----|------|
| **本次分支/组合包** | 一行点名 |
| **镜头** | 角度景别画幅，人话 |
| **主体** | 姿势→暴露→连接→表情，与英文同构 |
| **勿** | 大段重复英文专有名词不解释 |
| **可** | 点明「防崩：手插发」「连接：骑乘深坐可见根部」 |

释义长度：英文的 40–70%，清楚即可。

## 14. Diegetic 文本与纹身（场景自带的字与墨）

### 14.1 画面文字（diegetic text）

1. 用户给了 / 图上有可读字 → **双引号逐字写死 + 落面**（`"PRIVATE" etched on the key card`），可选字体提示。  
2. 场景天然有字而用户没给（街牌 / 包装 / 海报 / 菜单 / 手机屏 / 电梯面板）→ **发明短而可信的虚构文字**放引号内，语言贴合场景；不写真品牌、不写 URL。  
3. 远处不可读招牌 → `soft unreadable letterforms` 氛围即可；近焦点字 → 引号写死。  
4. 永不给：水印、平台 UI、签名、credit 线、二维码、时间戳。

### 14.2 纹身（用户/图暗示有纹身但模糊 → 补具体设计；**无暗示 → 绝不发明**）

- 三件套必写：**motif + style + placement**（`a fine-line blackwork moth on her left inner forearm`），不是空句「has a tattoo」。  
- 文字纹身：字放双引号 + 字体风格（hand script / old English / delicate cursive）+ 顺身体流向（锁骨横幅 / 前臂竖排 / 指节）。  
- 图案纹身：命名可读题材（moth / dagger-and-rose / wave band / 蛇绕前臂 / 胸骨 filigree…），大小贴合该处皮肤。  
- 多纹身：一套同风格族或有主次（主焦点 + 小件呼应），不成随机贴纸。  
- 常规位置：腕 / 内前臂 / 上臂 / 肩头 / 胸骨 / 脊柱 / 脚踝 / 耳后 / 髋 / 大腿；**不主动发明脸纹**。  
- 图中纹身不可读 → 换成该处清晰合理设计，不写 `blurry ink`（除非用户就要磨损褪色感）。
