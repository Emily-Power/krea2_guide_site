# 连接点句模库（Connection Templates）

供 `erotic-prompt` 在写 **Main subject** / 补丁句时直接套用或改写。  
**原则**：一帧只锁 1～2 个连接点；英文可嵌入四段模板；全员默认 18+。

用法：

1. 按行为选类 → 抄 1 条主句 → 按角色改 he/she/名称  
2. 可与「姿势锚点」「体液锚点」各拼半句  
3. 对照出图失败时，优先丢 **补丁句** 区的对应条
