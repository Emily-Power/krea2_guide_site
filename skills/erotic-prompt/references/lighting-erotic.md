## 2. 原则（强制）

1. **主光方向写清**（side / front-left / backlight rim / top-down）  
2. 阴影可塑形：`soft shadow under breast and along hip`  
3. 情色材质与光一致：油→硬高光；蒸汽→散射；直闪→硬边  
4. 亚洲肤：`warm-neutral East Asian undertone`，忌死黄/病绿钨丝失败  
5. 一帧 **1 主光** + 可选 **1 rim**；勿三色霓虹乱战  
6. **光服务行为**：主高光应落在 **敞开面 / 结合部 / 汗乳下缘**，不是只打背景墙  
7. 压缩时：**永不砍 L6 主光句**

```
key light: warm tungsten camera-left; thin cool rim from window; specular on wet skin only where moist
```

## 6. Boudoir / 摄影棚补强（2024–2026 常用）

| 手法 | 英文 | 说明 |
|------|------|------|
| 大柔光顶置 | large softbox overhead as key | 经典单灯私房 |
| 45° 大柔光 | large soft key at 45° | 奢华塑形 |
| 侧位挪机 | move camera around fixed side light | 同一灯出明暗两种情绪 |
| 轮廓 rim 分离 | rim from behind opposite key | 黑床上主体不融 |
| Beauty dish 硬边 | beauty dish + grid for fashion edge | 杂志感；慎用在素人脸 |
| 混合日钨 | gel or accept mixed WB | 窗+灯酒店真实感 |

焦段感（与 web-fill §13 一致）：脸/妆 **50–85**；环境全身 **35–50**；勿为“电影”乱写 anamorphic 除非用户要。

### 6.5 相机语系分道（amateur phone vs pro/cinematic · 二选一禁混）

**判定（≥2 线索才锁 phone lane）：** 竖屏习惯、直闪/混光、额头高光过曝、JPEG 软/块、高感噪点、轻微手抖、AF 不准、广角畸变、地平线歪、主体偏框、镜面里有手机、生活杂物背景、抓拍时机。干净棚拍/插画输入**不要**硬加 phone 颗粒。

| 语系 | 前载写法 | 允许 2–4 个线索 | 禁 |
|------|---------|----------------|----|
| **amateur phone**（素人/自拍/偷拍风） | `candid handheld smartphone photo` / `vertical phone snapshot, arm-length POV` 放首句 | on-camera flash；mild JPEG noise；soft imperfect autofocus on nearest skin；slight tilt OK；cluttered lived-in room | 85mm/f1.4 假 EXIF；8k/masterpiece 堆；CGI 词（octane/Unreal/ray tracing）；假摄影师入画 |
| **pro / cinematic**（默认） | `cinematic still with cinematic erotic photography` + 焦段（脸/妆 50–85，环境全身 35–50） | f/1.4–2.8 浅景深 或 f/8+ 环境深；softbox/window key；golden hour；可控 vignette | phone grit 词混入；裸 `photorealistic / realistic` 锚点 |

- 摄影类型（首句 `with` 后）默认 pro cinematic；用户说 自拍/偷拍/素人/party → phone lane。
- phone lane 场景道具从简，背景乱一点好过布景感。
- 光 ID 搭配：phone lane 常用 `el-hard-flash / el-ring-selfie / el-practical-only / el-screen-glow`；pro lane 全表可挑。
