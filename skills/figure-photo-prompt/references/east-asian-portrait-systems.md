# 东亚写真体系全谱（East Asian Portrait Systems）

> **SFW · 仅 18+。**  
> 覆盖日系杂志 / 韩系概念 / 中式旅拍 / 小清新 / 校园风 / 唯美 / 清冷 / 港风 / 台式文青 / 写真馆棚拍等。  
> 与 `young-asian-women-catalog.md` 正交：本卷偏 **风格体系配方**；彼卷偏年龄·肤发·主体。  
> 「少女感」= **youthful adult**，禁 teen/loli。  
> **人种：** 本 skill 全局默认 **East Asian**；用户指定其他人种时风格壳可保留、脸与肤按用户写。
