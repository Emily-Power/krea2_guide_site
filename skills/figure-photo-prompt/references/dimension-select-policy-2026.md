# 公共维点菜基数策略（Skill 内可执行 · 2026）

> **用途：** 写作前定「每个 group 选几个」——**不是**网站 UI 代码，是防止把互斥 L2 peer 写成同时成立。  
> **完整表：** 仓库 `docs/维度点菜策略-逐层分析.md`（有则优先）。本文件是 **skill 包内精简铁律**，离线也够用。  
> 三 skill **公共维同一套**；专属见文末。

---

## 0. 记号

| 记号 | 含义 |
|------|------|
| **S** | 该 group **只 1 个**词（组内互斥） |
| **M(n)** | 该 group 最多 **n** 个 peer 可同时写 |
| **V** | 跨 group **可叠**（纵向：造型+刘海+发态） |
| **H** | 同层多 peer（横向：多道具） |
| **X** | 整维单轴（人种/性别/尺度） |

**总优先级：** 用户原话 > 组合包 > 本策略填空 > 默认。  
**禁止：** 把同一 group 的多个 S 词写成同时成立（例：黑长直+丸子+马尾）。

### 1.1 发型反例 / 正例（必记）

| 错 | 对 |
|----|-----|
| 黑长直 + 长层次 + 披肩微卷 + 低马尾 + 凌乱丸子 | **只 1 个** L2造型 |
| （无修饰） | 黑长直 + 窗帘刘海 + 风动 + 自然黑（跨 group **V**） |

### 1.2 收到用户「一串 ID」时

1. 按 **group** 归类（或按中文名推断槽位）。  
2. 同 group 多个 S 词 → **只留用户最后点名 / 最具体的 1 个**，其余丢弃。  
3. 再写正文；释义可写：`已压造型互斥：保留 low_pony`。

## 3. 与「分支/组合包点菜」的区别

| | 公共维基数（本文件） | 广度点菜（breadth 等） |
|--|---------------------|------------------------|
| 管什么 | 一帧里发型/光/场 **写几个互斥词** | 题材菜单、组合包名 |
| 会不会五发型 | **禁止** | 无关 |

HMCP / six-axes 等「妆发 1 句、道具 ≤1」= **写作密度**；与本文件 **group 基数** 一致时取更严者。

## 4. 自检（交付前）

- [ ] 主发型造型 ≤1 · 主大姿 ≤1 · 主场景 ≤1 · 主光型 ≤1 · 主调色 ≤1  
- [ ] 妆壳 ≤1 · 表情壳 ≤1  
- [ ] 道具/暗示焦点若多，≤策略上限且非互斥硬拗  
- [ ] 未把「纵向叠层」理解成「同槽五个 L2」
- [ ] 成套协调：场景与光一致 · 材质与场一致 · 道具与锚共现 · 服饰与场景色调呼应
- [ ] 配件 0–1 主道具来自锚生态（figure 一帧 1 主 / youth 0–1 主 / erotic 一帧一主纪律不变）
