# 布光与构图（Lighting & Composition）— 全题材

人体摄影：**光塑造体积与功能可读性，构图决定人与世界的关系。**  
写入 `This is a…` 与 `Composition and atmosphere`。

### 1.1 宽光 / 短光（修正必会）

```
short lighting: key on the far side of the face, near cheek in softer shadow — slimming, dramatic
```
```
broad lighting: key on the near side of the face — wider, friendlier reading
```
```
mixed: face opened to key while body angles away so the torso reads narrower
```

## 6. 镜头语言（1～3 个，匹配题材）

| 题材 | 倾向 |
|------|------|
| 头像 | 85mm compression, shallow DOF |
| 街拍纪实 | 35mm environmental, deeper DOF optional |
| 运动 | fast-shutter freeze language, possible panning bg |
| 建筑环境 | 24–35mm sense of space（控制畸变） |
| 舞蹈 | full body + slight low angle for line |
| 航拍 | top-down orthographic feel |

```
85mm-style compression, creamy bokeh, subject separation
```
```
35mm reportage framing, environment readable, mild grain
```

## 7. Composition 段模板

**棚/时尚：**
```
Composition and atmosphere: [placement]; visual center on [garment line / face / pose]; [key]; [DOF]; [mood]; masterpiece, best quality…
```

**环境/纪实：**
```
…visual balance between figure and [place]; scale relationship [equal/dwarfed]; available light direction; documentary stillness…
```

**运动：**
```
…force line through [body]; frozen apex of motion; background simplified or streaked; impactful athletic still…
```

## 8. 失败补丁

| 现象 | 补丁 |
|------|------|
| 平光没体积 | 指定 key 方位 + shadow side |
| 纪实却棚拍光 | 改为 available / mixed practicals |
| 健身没肌理 | hard raking side + dry or light sweat |
| 环境人被拍成证件照 | 拉开人，写入建筑线与负空间 |
| 剪影糊成一团 | limbs separated, bright clean backlight field |
| 运动拖影过文戏 | freeze language: sharp limbs, dust/water suspended |
