# 姿势目录与身体建筑学（Pose Catalog）— 全谱

人体摄影提示词的核心是 **可读的身体结构**：重心、对侧、间隙、线条、**功能动作**。  
**S 曲线只是时尚站姿的一种，不是万能默认。**

一帧 **1 个主姿势族** + 可选 1 个手位修饰。按题材选章。

---

## 0. 身体建筑学（写之前默念）

| 原则 | 说明 | 英文种子 |
|------|------|----------|
| **重心** | 谁在承重 | `weight on the back foot` / `load on the front supporting leg` |
| **对侧** | 肩髋反向更立体 | `shoulders and hips counter-rotated` |
| **软关节** | 锁死=僵 | `soft knee` / `unlocked elbow` |
| **间隙** | 臂贴死躯干易糊 | `gap of light between arm and torso` |
| **功能优先** | 职业/运动先写任务动作 | `hands on the instrument / tool / hold` |
| **从支撑起摆** | 脚/坐骨/抓点 → 髋 → 脊 → 手 → 头 | base → spine → distal |
| **景别匹配** | 远景只写大姿态 | 见比例铁律 |

### 按题材选「主逻辑」

| 大区 | 姿势主逻辑 |
|------|------------|
| 时尚商业 | 线条、廓形、非常规美 |
| 纪实街拍 | 真实重心、行进、等待 |
| 运动 | 发力链、相位、平衡 |
| 舞蹈 | 延伸、外开/地面、表演形 |
| 职业 | 工具交互、工位朝向 |
| 艺术 | 雕塑站、剪影、古典引用 |
| 私房（仅点名） | 松弛坐靠 — **非默认** |

## 1. 时尚 / 商业站姿

### 1.1 S-curve
```
weight on her back leg, front knee softly bent, near shoulder angled to the camera, opposite hip gently popped, soft S-curve through the torso
```

### 1.2 Contrapposto
```
classical contrapposto: weight on one leg, free leg relaxed, standing hip higher, shoulders counter-tilt
```

### 1.3 Three-quarter
```
body at three-quarter angle, near shoulder closer, far hip receding, face returning to camera
```

### 1.4 Fashion power
```
staggered feet, tall spine, open shoulders, soft micro-bend in one knee; hands on hips or holding garment edge — confident not military
```

### 1.5 Avant geometric
```
deliberate angular pose: one arm bent sharp, weight shifted extreme, chin geometric; still anatomically plausible
```

### 1.6 Walking mid-stride（造型行走）
```
mid-stride, heel just down, coat or hem frozen mid-swing, opposite arm natural swing
```

### 1.7 Lean surfaces
```
shoulder or hip against wall/column, one sole up or ankle cross, casual editorial lean
```

### 1.8 Seated editorial
```
perched on seat edge, spine long, legs asymmetric (cross or angle), hands intentional on knee or seat
```

### 1.9 Crouch / low fashion
```
low crouch, asymmetric knees, weight on balls of feet, face up to lens — street or studio
```

### 1.10 Profile clean
```
true profile, long neck, stacked shoulders, simple hands
```

## 2. 纪实 / 街拍 / 环境（少「摆」多「遇」）

### 2.1 Waiting weight
```
weight on one hip, soft tired-or-calm stance, hands free or on bag strap, gaze off-camera into the environment
```

### 2.2 Commute hold
```
one hand on overhead rail or pole, feet staggered for train balance, torso slight sway freeze, neutral face
```

### 2.3 Work-in-progress
```
body oriented to the task (counter / machine / patient direction), hands mid-action with tool, face focused on work not lens
```

### 2.4 Environmental standing
```
full figure small-to-medium in frame, feet planted in real ground, posture tells occupation; environment reads first or equal
```

### 2.5 Crosswalk stride
```
decisive crosswalk step, body lean into walk, bag motion, city geometry around
```

### 2.6 Conversation lean
```
two adults angled toward each other, weight casual, hands mid-gesture, not mirrored stiff twins
```

## 3. 运动 / 体能

### 3.1 Athletic lunge
```
front knee over ankle, back leg long, torso stacked, core braced; hands free or on gear
```

### 3.2 Power stance / ready
```
wide base, knees soft, hips under shoulders, center of mass low, hands guard or on implement
```

### 3.3 Run phases
- 腾空：`airborne stride, rear leg extended, front knee drive, opposite arm forward`  
- 支撑：`single-leg support mid-stance, slight forward lean, arm swing freeze`

### 3.4 Lift lockout / pull
```
barbell at clear height (hang / rack / lockout), grip visible, spine neutral, effort face controlled
```

### 3.5 Climbing
```
body close to wall, three-point contact named, hips in, reaching limb elongated
```

### 3.6 Martial structure
```
bow/horse/fighting stance with named weight split (e.g. 60/40), guard hands, rooted feet
```

### 3.7 Yoga asana（写支撑）
```
[asana]: grounded points listed, long line through spine, shoulders away from ears, calm breath face
```

### 3.8 Swim block / stroke
```
coiled on starting block / mid-stroke arm extension, streamline head, water interaction
```

### 3.9 Cycle posture
```
low aero or endurance posture on bike, hip angle clear, hands on drops/hoods, road blur optional behind
```

## 4. 舞蹈 / 舞台

### 4.1 Ballet line
```
supporting leg turned out and straight, working leg extended (arabesque or a la seconde), arms in a named port de bras shape, lift through crown
```

### 4.2 Contemporary off-axis
```
off-balance beauty: spiral through spine, one hand to floor or knee, weight mid-transfer, expressive distal fingers
```

### 4.3 Floorwork freeze
```
on floor with clear contact surfaces (hip, shoulder, shin), limbs drawing space, face direction intentional
```

### 4.4 Hip-hop freeze
```
power freeze readable: kickstand or hollow-body hold, sharp angles, sneakers planted
```

### 4.5 Ballroom frame（双人）
```
dance hold: closed or promenade frame, spine tall both, clear lead-follow arm structure, equal adult partners
```

### 4.6 Stage projection
```
gesture large enough for balcony: open chest, extended arm, weight forward, face to imaginary house
```

## 9. 补丁句

**僵直证件照：**
```
not stiff passport stance; real weight shift, soft knee, shoulder angle OR task-oriented posture
```

**误用私房靠床：**
```
replace bedroom lounge with subject-appropriate stance: work / walk / athletic / editorial stand
```

**运动假用力：**
```
clear force vector: grounded base, stacked joints, implement load path visible
```

**舞蹈粘肢：**
```
limbs separated in space, supporting vs working leg explicit, fingers finished
```
