# 模型提示策略 — Krea 2 / Seedream（SFW）

> 执行默认：**Krea 2 + 六层完整句 + 高密四段空行版式 + 全文约 200–380 词**。  
> 点名 Seedream：**同结构、更精炼**；鼓励附形态 B。

分层细节 → [`krea2-qwen-te-layered-prompting.md`](krea2-qwen-te-layered-prompting.md)

---

## 1. 默认：Krea 2

| 要做 | 说明 |
|------|------|
| 加载（用户问时） | CLIPLoader **type=`krea2`**，权重 `qwen3vl_4b_*` |
| 句式 | 自然语言完整句 |
| 结构 | 六层（镜头→动作→衣→材质→光→场） |
| 篇幅 | Main 100–180；全文 **200–380**；超过约 420 词先压缩；**四段空行** |
| 压缩 | 先砍 Env/重复；**不砍动作与主光** |
| 正向 | 写要什么；少「不要/无」 |
| 画幅 | 竖 3:4 / 2:3 / 9:16 常见 |

Turbo：缩环境，保镜头+动作+主光。

---

## 2. Seedream / 即梦（点名时）

| 要做 | 说明 |
|------|------|
| 质量 | 同一五标准 + 六层 |
| 风格 | **精确、少华丽空词**；核心靠前 |
| 形态 | 可出完整 A；**鼓励附 B** 作粘贴投喂 |
| B 篇幅 | 4.x 常约 **30–100** 词；5.x 常约 **50–150** 词 |
| B 顺序 | 身份+姿 → 衣 → 表情 → 场 2–4 → 主光+摄影类型 |
| 编辑 | `Keep face/hair/body. Change only pose/light/outfit.` |
| 画面字 | 短词 + 引号 + 位置 |

能力：指令遵循、写实、编辑、文字进画、高分辨率——**用精炼写满结构，不是写空壳。**
