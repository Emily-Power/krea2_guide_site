# 深度扩展（Depth Expansion）— 全题材

在正文五标准之上的 **加分项**。形态 A 建议至少命中 **3 项**。  
不同大区的「深」不一样：**健身的深 ≠ 街拍的深 ≠ 芭蕾的深**。

---

## 0. 反私房默认

写深度时 **不要** 自动堆：潮红、湿唇、半褪、床品、暧昧眼神。  
除非用户明确 I 区私房且 SFW，否则深度应落在：

- 结构（骨/肌/关节）  
- 功能（发力、工具、职业动作）  
- 空间（人与建筑/自然尺度）  
- 光体积  
- 材质与时间痕迹

## 7. 题材专章深度（写该类必看）

### 7.1 时尚编辑

- 非常规：髋推、肩压、手「奇怪但稳」  
- 服装结构点：驳头、开衩、垂坠方向  
- 姿态服务 **衣服**，不是服务暧昧  

### 7.2 电商 lookbook

- 全身比例真实、颜色准、少戏剧扭曲  
- 脚进画、袖长/裤长可读  
- 光均匀，阴影不吞版型  

### 7.3 街拍 / 报道

- 「被撞见」的真实重心，而非棚拍 S 线硬套  
- 环境锚 2～4 个即可，主体动作功能化  
- 可有轻微运动模糊在背景，主体仍实（文案暗示 shutter feel）  

### 7.4 健身 / 健美

- 写清 **哪块肌在收缩展示**  
- 关节排列安全合理（膝不过度内扣）  
- 汗=训练语境，不写情色油光叙事  

### 7.5 舞蹈 / 舞台

- 支撑腿 vs 工作腿  
- 远端延伸（指尖、脚尖）  
- 服装跟随惯性的 **一个方向**  

### 7.6 职业环境人像

- 人与工具/工位的空间逻辑  
- 防护装备穿戴正确感  
- 表情=职业专注，不是广告假笑（除非广告）  

### 7.7 艺术人体 / 明暗

- 像雕塑：骨点、体积转折、投影形状  
- 灰阶设计：高光面积占比  
- 严禁性化局部特写  

### 7.8 运动动作定格

- 动作相位：腾空最高点 / 触地缓冲 / 出手瞬间  
- 重心投影与支撑关系  
-  equip 位置合理（球、拍、杖）  

### 7.9 水下

- 水平或微倾的漂浮轴  
- 发与布的垂直浮起方向  
- 焦散与气泡层次  

### 7.10 群像

- 主焦点 1 人写满，他人位置+1 动作  
- 头高错落、前后层  
- 避免每人平均描五官  

### 7.11 姿势×光同设计（全网核心）

- 先定主光，脸 **转向 key**（鼻朝光更干净）  
- 或脸开朗、身体短光（肩背显瘦）  
- 戏剧光必须有匹配的侧脸/侧身，忌光平姿也平  

```
face turned into the key; body may angle away for a narrower torso reading
```

### 7.12 修正性姿势（尊重 · 非羞辱）

| 目标 | 深度写法 |
|------|----------|
| 视觉显瘦 | 身体 45°、短光、后脚重心、腰微前倾 |
| 增强存在 | 肩更正、略仰机位、开阔站距 |
| 丰满友好 | 髋稍后、躯干略前倾镜头、手臂与躯干留缝 |
| 修颈脸 | 下巴微前伸离开脖子、拉长颈 |

### 7.13 体育：冻帧 vs 动感

- **冻帧**：尖利肢体、尘土/水/雪悬浮、峰值瞬间  
- **跟随拖影**：背景拉丝、主体相对清晰  
- **前方留白**：运动方向一侧多留空间  
- **机位**：尽量人脸/号码朝镜头的一侧  

### 7.14 舞蹈机位

- 跳跃：低机位夸大高度  
- 芭蕾：远端脚尖进画、外开可读  
- 街舞：略仰或平、城市硬光  
- 先写结构再写舞种名；名不确定就写结构  

### 7.15 攀岩 / 冒险

- 优先 **完全伸展、四肢可见** 的动态  
- 人与岩壁/山谷尺度  
- 侧逆光刮岩面纹理  

### 7.16 舞台 / 演唱会

- 追光皮肤正确曝光，周围可死黑  
- 允许饱和色光：`magenta and cyan stage gels`  
- 轮廓发丝光、持麦或道具接触点  
- 可选轻微动感或完全冻帧，二选一  

### 7.17 婚礼 / 仪式（SFW）

- 步态、挽臂、戒指手部、回眸峰值  
- 裙摆/礼服结构的惯性方向  
- 人群虚化，主身份身体关系清晰  
- **禁止** 写成情色私房  

### 7.18 魅力肖像 Glamour SFW

- 妆发造型优先 + 魅力光（蚌式/柔硬混合）  
- 着装完整或用户指定；与 I 区私房区分：更「美容广告」而非卧室  

### 7.19 实验媒介

- 长曝残影、双重曝光、光绘、频闪感、棱镜：各写 **一种光学/时间机制**  
- 主体姿态仍须可读，机制服务形态  

### 7.20 微距身体局部（非性化）

- 手、眼周、皮肤纹理、腕表与骨点  
- 景深极浅、焦点声明  
- 禁止性器化局部  

完整行业映射与 combo 补强 → [`genre-depth-web-2026.md`](genre-depth-web-2026.md)

### 7.21 年轻女性 18–30 / 少女感成人（SFW）

- **年龄英文锁死**：early / mid / late twenties，禁 teen  
- 「少女感」= youthful adult 清透、轻快；**脸必须成人比例**  
- 手：触发、包带、插袋 — 少死手  
- 线条：软 S 线或松弛歪重心，忌军人站

### 7.22 亚洲女性肤与光

- 大柔光/窗光友好水光与通透感  
- 逆光写发丝 rim + 面部填充或半剪影意图  
- 白平衡：自然 undertone，避免死黄绿橙喷雾假晒  
- 深一度亚洲肤：`expose for the face`  
- 妆发只写 1 套系统（日系自然 / 韩系 glass / 清冷雾面…）  
- 反刻板：不写贬义眼型词；细节仅用户要求时写 monolid/double eyelid
