# 人体摄影广度点菜（Breadth Catalog）— 全谱系

> **本 skill 不是私房/柔美人像专精。**  
> 「人体摄影」= 一切以 **人体结构、姿态、运动、职业、环境关系** 为视觉中心的摄影类型。  
> 私房 / boudoir 仅是 **A 区中的一个可选小类**，且默认 **不自动启用**。

用户说「有哪些拍法」时：**按大区精简点菜**，勿贴全文。  
点菜后必须用 **output-prose-quality** 写成可画正文。

# 伪随机铁律（「随机/换一组/再来一个/冷门」触发时强制）

1. **种子（LLM 可手算）**：`seed = (今天日期 YYYYMMDD 各位数字之和 + 用户本轮输入字数) mod N`，N = 本线随机池表长（§M 冷门池 1–40）。环境有 hash 工具时用 `hash(日期+输入串) mod N`；禁止「随便抽一个」。
2. **抽取**：从 seed 对应 index 起顺序取第 1 个可用项（跨池回绕）；单次会话已用 index 不回卷。
3. **「换一组/再来一个」= index+1**，且**强制更换核心三维**：主场景 + 大姿势 + 主光；脸/发型/体型沿用连续锁。
4. **随机模式硬禁用**：soft-recommend §2.1 主推行、常青 combo 默认行、默认快配表第一行——只从冷门池/富库抽取。
5. 释义标注：`随机抽取: seed=<值> index=<i> → <场/姿/光>`。
