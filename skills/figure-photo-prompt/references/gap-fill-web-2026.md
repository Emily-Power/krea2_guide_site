## 17. 证件照 / 形象照 · 深度（检索加深）

| 项 | 写法 |
|----|------|
| 身份 | adult East Asian, 年龄明确 |
| 朝向 | facing camera squarely, both ears visible if ID-strict |
| 光 | even soft frontal 或 轻 butterfly；**忌**分割/伦勃朗戏剧 |
| 背景 | plain white / light gray / pale blue — 单色干净 |
| 表情 | neutral or soft professional smile；双眼平视镜头 |
| 服 | solid color with clear neckline and shoulder line；忌大花、低领夸张 |
| 妆 | natural light makeup；忌浓烟熏 |
| 修图感 | clean skin but identifiable，勿整容脸 |

**上下夹光 / 左右夹光（形象照美化）：**  
soft key slightly above front + gentle under fill 或 	wo soft equal lights 45° for even beauty ID look

**与简历头像差：** 证件更「规范正面」；简历可浅景深、微侧肩、环境虚化。
