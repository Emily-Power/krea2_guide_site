# 纯欲 / 独处诱惑布光（youth-seduction）

原则：**主光方向写清**；光落在 **暗示区体积**（锁骨、腰窝、大腿上缘、湿肩）；亚洲肤 `warm-neutral East Asian undertone`，忌死黄绿。

在 `Composition and atmosphere` 中应有明确主光；Main 末句可复述落点一次。

## 2. 写法规则

1. **一个主光** + 可选一个 rim/spill；不要三种主光抢戏。  
2. 写 **落点**：`key sculpting the collarbones and the strip of midriff`  
3. 暗示区无光 → 欲望读不出；补 L6。  
4. 亚洲肤：`warm-neutral East Asian undertone`；浴后可 `dewy`；夜戏可 `soft sheen`。  
5. 压缩时 **永不砍主光句**。

## 3. 可直接粘贴的 Comp 句

**钨丝卧室：**
```
Warm bedside key from camera-left sculpts collarbone and the open shirt edge; deep soft falloff behind her; quiet intimate night mood.
```

**窗侧：**
```
Soft window key at forty-five degrees lights the near cheek and waist hollow; gentle room fill; shallow DOF on background clutter.
```

**屏光：**
```
Cool phone-screen light under the chin and eyes as primary key; a dim warm lamp in the far corner; intimate private-night still.
```

**蒸汽浴室：**
```
Steam-diffused warm vanity light wraps dewy skin; specular beads on shoulder; fog softens edges without losing face readability.
```

**霓虹：**
```
Magenta-cyan neon spill from the window rims her shoulder; warm practical lamp holds face exposure; urban night solitude.
```

## 4. 失败 → 补丁

| 现象 | 补丁 |
|------|------|
| 光平像证件 | add key direction + shadow side + falloff |
| 脸亮身死 | key must also hit collarbone/waist implication zone |
| 全画面过曝 | controlled key, preserve shadow for intimacy |
| 霓虹变赛博脏 | one neon rim + clean warm face key |
| 蒸汽糊脸 | face clear in cleared mirror patch or closer key |

## 6. 四次全网扩 · 布光深度句（2025–26 教学内化）

**单灯 45°：**
```
Single soft key at forty-five degrees, slightly above eye line, sculpts the near cheek and collarbone; far side falls to soft shadow; optional wall bounce as gentle fill.
```

**条形侧光塑形：**
```
A tall narrow side light rakes the waist hollow and hip curve under fabric; spill controlled so the face stays readable; wall stays dark enough for separation.
```

**主光+轮廓：**
```
Warm key holds the face; a thin rim from behind separates shoulder and hair from the dark room; intimate low-key still.
```

**高键极简（趋势）：**
```
Bright soft natural light, almost minimal shadows, uncluttered background; desire reads from pose and half-lidded eyes rather than heavy mood lighting.
```

**窗逆+薄补：**
```
Strong window backlight rims hair and shoulder; a whisper of bounce keeps eyes alive; silhouette soft not pure black cutout.
```

### 失败+

| 现象 | 补丁 |
|------|------|
| 单灯变阴阳脸毁容 | raise key slightly, add wall bounce fill |
| strip 光变舞台射灯 | soften, keep face key readable |
| 高键变证件闪光 | keep soft window quality, not on-camera flash unless digicam |
| 低调变恐怖片 | warm key pool, no cyan horror, eyes catchlight |
| 只写 cinematic lighting 空词 | 必须点名方向+落点+1 实用源 |
