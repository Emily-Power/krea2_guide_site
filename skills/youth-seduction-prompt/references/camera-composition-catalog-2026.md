# 镜头 · 构图 · 景别深库 2026 — youth-seduction

> **用途：** 专补 **Camera / Lens / Framing / Composition**（L1 层）的广度与可画深度。  
> **边界：** 成人 early twenties · 默认东亚 · **暗示非露骨** · 默认 **solo**。  
> **交付：** 镜头 1 句写清角度+景别+画幅；构图服务 **姿 + 暗示焦点 + 主光**，不抢戏。  
> **叠用：** 光 → `lighting-youth-seduction.md`；姿 → hmcp / implication-pose；场 → scene。

**检索内化源（2025–2026）：** 欧美 soft boudoir 教学（窗光位、单灯 45°、strip 侧光塑形、浅景深 f/1.4–f/2 语感）、人像三分法/负空间、TikTok·小红书竖屏 bed/mirror selfie 构图、酒店大窗机位、中文居家氛围感取景口诀。

---

## 0. 镜头写法铁律

| 规则 | 说明 |
|------|------|
| L1 一句写满 | angle + distance + aspect + optional lens feel |
| 默认 | **eye-level 或 soft-low** · **medium / medium-close** · **vertical cinematic** |
| 景别匹配细节 | 远景禁写毛孔唇釉；MCU 可写卧蚕水光 |
| 一帧一机位 | 禁止「推镜头再切特写」时间线 |
| 构图服务暗示 | 主体/眼神/锁骨落在力量点；负空间给窗/墙/暗 |

**句模（嵌开篇 This is a … · 高密四段）：**
```
This is a [angle] [distance] [aspect] [still] with [intimate cinematic photography]: a photoreal adult East Asian woman frozen [phase], [skin finish], solo self-display toward the lens.
```

例：`This is an eye-level medium vertical 3:4 cinematic still with intimate lifestyle photography: a photoreal adult East Asian woman frozen mid-glance on rumpled sheets, soft product-clean skin, knowing gaze toward the lens.`

## 1. 角度 cam-ang-*（Camera Angle）

| ID | 中文 | 英文锚 | 欲感 | 注意 |
|----|------|--------|------|------|
| **cam-eye** | 平视默认 | eye-level camera | 对被观看最自然 | **默认** |
| **cam-soft-low** | 微仰 | slight low-angle looking up | 拉长腿/下巴利落 | 勿过度畸变 |
| **cam-low-full** | 低机位全身 | low angle full-body | 镜前/站姿气场 | 头勿贴天 |
| **cam-high-soft** | 微俯软 | gentle high-angle looking down | bed selfie / 躺姿 | 勿压扁脸；**成人骨相** |
| **cam-high-bed** | 床上俯拍 | high above bed looking down | 仰躺发散经典 | 服/sheet 写死 |
| **cam-over-shoulder** | 过肩 | over-shoulder toward mirror or window | 自赏/出画 | 肩不挡脸 |
| **cam-profile** | 侧脸 | pure profile | 清冷/白月光 | 眼神可前可闭 |
| **cam-three-q** | 3/4 | three-quarter face and body | 纯欲最高频 | 默认站/坐 |

## 2. 景别 cam-dist-*（Shot Distance）

| ID | 中文 | 身体范围 | 可写 | 禁 |
|----|------|----------|------|-----|
| **dist-ecu** | 大特 | 眼唇/锁骨一区 | 水光唇、卧蚕、细链 | 全身姿 |
| **dist-cu** | 特写 | 脸+颈 | 表情、发丝、妆 | 膝脚 |
| **dist-mcu** | 中近景 | 头至胸廓/锁骨下 | **默认纯欲 MCU** 妆+锁骨 | 完整腿姿 |
| **dist-ms** | 中景 | 头至髋/膝 | **默认姿可读** 服状态 | 环境过多 |
| **dist-mls** | 中远 | 膝上全身偏 | 沙发姿、窗倚 | 脸过小慎写细妆 |
| **dist-fs** | 全身 | 头到脚 | 镜前、靠墙脚抵 | 毛孔级细节 |
| **dist-ws** | 远景 | 人+大环境 | 窗边小人物、阳台 | 五官/微汗丝 |

**比例铁律（与 SKILL 一致）：**  
- 中景及以下 = 画面主体，允许表情与材质。  
- 远景 = `small figure by the window`，不写毛孔。

## 3. 画幅 cam-asp-*（Aspect）

| ID | 触发 | 英文 | 适用 |
|----|------|------|------|
| **asp-v23** | 竖 2:3 | vertical 2:3 | 写真默认、分镜 |
| **asp-v34** | 竖 3:4 | vertical 3:4 | **小红书封面** |
| **asp-v916** | 竖 9:16 | vertical 9:16 full-frame phone | bed selfie / 抖音 |
| **asp-sq** | 方 | square 1:1 | 镜自拍 crop 可选 |
| **asp-h32** | 横 3:2 | landscape 3:2 | 窗纱全身、少用 |
| **asp-cin** | 电影感 | cinematic still framing | 默认氛围词可叠 |

**默认：** 竖 **2:3 或 3:4** + cinematic。用户说封面 → **3:4**；说短视频截帧感 → **9:16**。

## 4. 焦段感 cam-lens-*（Lens Feel · 勿堆参数墙）

> 文生图写 **焦段语感 + 景深结果**，不必写真实 f 数堆砌；可选 1 个。

| ID | 中文 | 英文锚 | 宜搭 |
|----|------|--------|------|
| **lens-35** | 环境叙事 | 35mm environmental feel, more room context | 场重要时 |
| **lens-50** | 自然眼 | 50mm natural perspective | 中景默认 |
| **lens-85** | 人像压缩 | 85mm portrait compression, soft background | MCU 脸+锁骨 |
| **lens-soft-tele** | 轻长焦 | short telephoto, subject isolation | 清冷/quiet |
| **lens-wide-soft** | 微广（慎） | mild wide, careful distortion | 镜前全身 · 勿鱼眼脸 |
| **lens-phone** | 手机感 | phone-camera perspective, front-camera high optional | 自拍 |
| **lens-film** | 胶片感 | film still look, gentle grain optional | aes-film / digicam 叠 |

**景深：**  
- 默认：`shallow depth of field, soft background bokeh`  
- 环境要清：`deeper focus, readable room anchors`  
- 破碎/夜：`subject sharp, room falls soft dark`

## 5. 构图 cam-comp-*（Composition）

| ID | 中文 | 英文锚 | 何时用 |
|----|------|--------|--------|
| **comp-thirds-eye** | 三分眼 | eyes on upper third line | MCU 经典 |
| **comp-thirds-body** | 三分身 | body on left or right third, space to gaze | 窗边/侧身 |
| **comp-center-soft** | 中心软 | soft centered subject, intimate symmetry | 镜对视、白月光 |
| **comp-neg-space** | 负空间 | large empty wall/window negative space | 清冷/距离欲 |
| **comp-lead-window** | 窗引导 | window frame as leading lines toward her | 窗专题 |
| **comp-lead-rail** | 栏/扶手引导 | rail or bed edge leading into frame | 阳台/床沿 |
| **comp-frame-door** | 门框套 | door frame secondary frame | 浴门后、玄关 |
| **comp-mirror-double** | 镜双 | true body + reflection balanced | 镜前 · 防崩 |
| **comp-crop-tight** | 紧裁 | intentional tight crop at midriff or thigh | 暗示区 · 勿硬核 |
| **comp-headroom-short** | 头顶紧 | short headroom, modern editorial | digicam/竖屏 |
| **comp-look-space** | 视线空间 | more empty space in gaze direction | 出画凝视 |
| **comp-diagonal-body** | 身体斜线 | body creates soft diagonal across frame | 侧躺/跪撑 |
| **comp-floor-sit** | 下三分坐 | subject in lower two-thirds, ceiling soft | 坐地姿 |
| **comp-bokeh-bg** | 虚化背景 | clutter soft bokeh, face/collarbone sharp | 生活脏不抢 |

**构图深度句（Comp 段可嵌 1）：**
```
eyes sit on the upper third; collarbone catches the key; soft negative space of the window to her left
body forms a gentle diagonal across the vertical frame; shallow DOF melts the room clutter
mirror reflection balanced left, true body right; both match pose exactly
```

## 9. 与七层 / 正文的位置

| 层 | 写哪 | 例 |
|----|------|-----|
| L1 | 开篇 This is a… | angle + distance + aspect + **with photography type** + 定格 |
| Comp 段 | Composition and atmosphere | **占框** + 构图 1 句 + 主光落点 + DOF + 质量词 |
| Main | 一般不重复焦段 | 除非 MCU 需强调 compression |

**压缩序：** 先砍环境与次要构图词；**保留** angle+distance 一句 + 主光。

## 10. 失败 → 补丁

| 现象 | 补丁 |
|------|------|
| 像证件照 | slight weight shift, soft-low or three-q, not stiff frontal ID |
| 脸畸变 | avoid extreme wide; prefer 50–85 feel; adult proportions |
| 俯拍幼态 | soft high only; adult facial bone; early twenties lock |
| 全身头贴边 | add headroom or reframe ms |
| 镜中双胞胎错 | reflection matches pose exactly |
| 空有滤镜无构图 | add thirds / diagonal / neg-space one clause |
| 9:16 头脚被切烂 | full-body: leave ankle/foot margin; mcu: lock collarbone in frame |
