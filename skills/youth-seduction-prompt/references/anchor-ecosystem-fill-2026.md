# 锚定成套生态表 2026 — youth-seduction（居家纯欲/暗示）

> **用途：** 用户点名单品/版型/场景/光/配件「怎么搭/成套/给个场景」且有空维时，
> 按该锚的**成套生态**补全空维：服饰状态、场景锚、道具 0–1、光、姿、镜头感、**色彩协调**，成套一致。
> **不是答案库**：主推 + 1～2 备选；用户已写维**永不覆盖**；联网可用时先联网内化，本表保底。
> **同锚冲突**：本表 > soft-recommend §2.1（§2.1 是冷门锚兜底）；组合包已预填的维不覆盖。
> 边界：成人 early twenties；暗示非露骨；场景独处为主。

## 0. 铁律

| 允许 | 禁止 |
|------|------|
| 空维按锚生态成套补（`男友衫锚：单扣+裸腿+床沿+钨丝+抱膝+米白主暖调`） | 只补一件衣服，其余维自由发挥 |
| 联网新生态 ≥2 来源共识 → 当次使用 + 季度回流本表 | 单帖内容当「2026 定式」写死 |
| 同锚走备选换线（第二套生态） | 同锚只背一套 |
| 色彩协调写 1 句（主色+点缀+整体调，可引用 L5 衣色词 col_*） | 只写衣色不看场景色调；黑白灰三连 |
| 道具 0–1 主且与锚共现；服饰状态精确到扣/带/摆 | 锚=浴袍却塞跨生态道具；状态含糊 |

## 2. 锚生态 → 空维映射（写作时执行）

1. 点名锚 → 查 §1；命中 → 主推成套填空维；用户说「换个风格/反差」→ 备选或跨区混搭，释义标 `偏离锚生态`。
2. 未命中 → 回退 soft-recommend §2.1/§2.2 → 默认快配 → 自由补全。
3. 场景空维且无锚 → 按风格生态推导；「随机」→ 伪随机取模（breadth-combo-catalog 伪随机铁律）从 scene 61–95 / web-fill §12 抽取。
