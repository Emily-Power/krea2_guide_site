# 维度点菜策略 · 逐层分析（L1 → group → 词）

> **诚实说明：** 上一版导演台修复是「按 L1 字段 + group 默认」的粗策略，**不是**三 skill 每个词逐条审完。  
> 本文是补完的 **嵌套规则真源**（公共维三 skill 共用 + 专属分轨）。  
> 实现：`skill-guide-site/assets/director.js` → `FIELD_POLICY`（按 option.`group`）。

---

## 0. 三种原子规则 + 两种嵌套形态

### 0.1 原子（对某个 group 内的词）

| 记号 | 名 | 含义 |
|------|-----|------|
| **S** | 组内单选 | 该 group 最多 1 个词（互斥 peer） |
| **M(n)** | 组内多选 | 该 group 最多 n 个 peer 可同时成立 |
| **∅** | 不参与 | 本 skill 隐藏/不写 |

### 0.2 嵌套形态（L1 容器怎么拼）

| 形态 | 读法 | 例子 |
|------|------|------|
| **V 纵向叠层** | L1 = 多个 **槽位** 串联；槽位之间可同时有值；**槽位内部**各自 S 或 M | 发型 = 造型S + 刘海S + 发态M(2) + 发色S |
| **H 横向多选** | L1 本身就是「同层多个 peer」 | 道具 = 杯+书+包 |
| **X 整维单选** | L1 只有一个互斥轴，无子槽（或只有一个 group） | 性别、尺度 intensity |

用户说的两种都合法：

1. **L1 单容器 · L2 槽 S · L3 槽 S**  
   → 黑长直(S) + 窗帘刘海(S) + 自然黑(S)  
2. **L1 单容器 · 某 L2 槽 M · 其子 L3 在「已选某 L2」前提下再 S 或 M**  
   → 衣着：上装S + 下装S（横向槽）+ 状态 M(3)；且 `L3半裙` 语义上依赖 `skirt`，但仍是 **半裙 group 内 S**

「依赖」用写作纪律表达（选了连衣裙才写连衣版型）；UI 层先用 **group 限流**，不强做「未选父则禁用子」（可二期）。

## 1. 公共 L1（Figure / Youth / Erotic 共用同一套）

三 skill **同一 catalog 公共树**；差异只在专属维与分轨表情显隐。

### 1.1 `subject` 拆成子 L1（导演台独立字段）

| 子字段 | 形态 | group | 规则 | 词例（互斥说明） |
|--------|------|-------|------|------------------|
| eth | **X** | L2人种 | **S** | eastasian / white / mixed… **不可**东亚+白人 |
| age | **V** | L2年龄 | **S** | e20 / m20 / t30… 主年龄带只 1 |
| age | **V** | L3年龄带 | **S** | y18_22 / y23_26… 与 L2 可叠一句细化，**组内仍 S** |
| sex | **X** | L2性别 | **S** | woman / man / androgynous |
| body | **V** | L2体型 | **S** | slim / curvy / athletic… 主型只 1 |

### 1.2 `cast` 人数

| group | 规则 | 说明 |
|-------|------|------|
| L2人数 | **S** | solo/duo/group/mirror… **不可** solo+duo |

### 1.3 `hair` 发型（你截图的核心）

| group | 规则 | 说明 |
|-------|------|------|

## 3. 三 skill 是否要「逐 skill 不同公共规则」？

| 结论 | 说明 |
|------|------|
| **公共维规则三 skill 相同** | 同一 `dimension_items` / 同一导演台 catalog；发型造型互斥不因 erotic 变合法 |
| **专属维各自表** | 上表 §2 |
| **写作边界不同** | Figure 慎内衣默认；Youth 不写连接点；Erotic 可写连接——这是 **内容边界**，不是多选 cardinality |

## 4. 与实现的对应

| 文档概念 | `FIELD_POLICY` |
|----------|----------------|
| X 整维单选 | `mode: "single"` |
| V 纵向 | `mode: "vertical"` + `defaultGroupMax: 1` + 部分 `groupMax` |
| H 横向 | `mode: "free"` |
| 跨组互斥 | `exclusiveGroupSets` |
| 组内 M(n) | `groupMax: { "L3状态": 3 }` |

软推荐 merge → `sanitizePickList` 按上表清洗。

## 5. 维护清单（改词时必做）

1. 新词必须带正确 **`group`**（决定互斥桶）。  
2. 新 group 写入本文 + `FIELD_POLICY.groupMax`。  
3. 若「子词依赖父 L2」，在 catalog 注释或本文写依赖；UI 禁用可二期。  
4. 禁止再把整维 `hair/cloth` 设成无 group 的 free multi。
